### Focus Areas

* **Simulation & Engine Architecture:** Designing decoupled, headless simulation cores and deterministic tick loops with complete isolation between domain state logic and UI presentation adapters.
* **Full-Stack Web Engineering:** Building responsive, edge-ready applications utilizing modern TypeScript frameworks, reactive audio context architectures, and lightweight data persistence.
* **Automation & Infrastructure:** Writing clean, modular command-line utilities and structured automation scripts to enforce repeatable builds and environment consistency.

### Core Engineering Principles

* **Decoupled Architecture:** Business logic and state management remain isolated from external engines and presentation frameworks.
* **Deterministic Execution:** Predictable, discrete execution ticks enable headless benchmarking, seamless unit testing, and reproducible states.
* **Automation-First Operations:** Eliminating manual setup and maintenance via modular scripting, strict sanitization, and structured pipelines.
